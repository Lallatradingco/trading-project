    How to read a pick

    • Trigger is the pattern's breakout level. A breakout trigger fires only if price trades through it; a fresh-breakout pick uses the last close as its reference.
    • Stop is half a day's average range (ATR 14) beyond the trigger, or the pattern's own stop if that is tighter. Target is one ATR, or the pattern target if nearer.
    • Hit rate is how often this pattern on daily charts reached its full target before its stop across all scanned NSE stocks. It describes the pattern type, not this trade.
    • Built from daily candles. There is no live intraday feed here, so check the price action at the open before acting.
